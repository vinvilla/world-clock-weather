# World Clock v2 — Design Document
**Project:** World Clock & Weather Dashboard
**Feature:** Auth + Supabase city persistence + city management + smaller cards + strip tooltip
**Date:** 2026-03-08
**Status:** Approved

---

## Overview

Three parallel upgrades that transform the dashboard from a hardcoded single-user app into a personalised multi-user product:

1. **Auth + Supabase persistence** — Supabase Auth (email/password) + `user_cities` table so each user owns their own city list, saved across sessions
2. **City management** — inline ✕ remove button on each card, "+" ghost card to add cities via OWM geocoding + `tzlookup`, max 6 cities (3-per-row grid)
3. **Strip tooltip** — hover over the DayNightStrip bar to see local time at any UTC offset; snaps to a city's full data when within ±1.5h of a pin
4. **Smaller cards** — reduced padding and font sizes so 6 cards sit comfortably in 3 columns

No changes to the AI panel, solar computation, or weather fetching logic.

## Supabase Schema

### Table: `user_cities`
```sql
create table user_cities (
  id          uuid primary key default gen_random_uuid(),
  user_id     uuid not null references auth.users(id) on delete cascade,
  name        text not null,
  lat         float not null,
  lon         float not null,
  timezone    text not null,   -- IANA, e.g. "Asia/Kolkata"
  owm_query   text not null,   -- e.g. "Chennai,IN"
  position    int not null,    -- display order 1–6
  created_at  timestamptz default now()
);

-- RLS: users can only see and modify their own rows
alter table user_cities enable row level security;
create policy "own rows" on user_cities
  using (user_id = auth.uid())
  with check (user_id = auth.uid());
```

### Seed data
On first login (no rows yet), insert the 5 default cities:
New York, Los Angeles, London, Chennai, Singapore — same lat/lon/timezone as the current hardcoded CITIES constant.

## Data Flow

```
App mounts
  └─ supabase.auth.getSession()
       ├─ null  → render <AuthOverlay onLogin={...} />
       └─ user  → loadCities(user.id)
                    └─ SELECT * FROM user_cities WHERE user_id = ? ORDER BY position
                         ├─ rows found  → setCities(rows)
                         └─ empty       → insertDefaults() → setCities(defaults)

Cities state → existing weather fetch, solarMap, DayNightStrip all unchanged
```

### Add city flow
```
User types in AddCityCard input (debounced 400ms)
  └─ GET /api/geocode?q={input}  (backend proxies OWM /geo/1.0/direct)
       └─ returns [{name, lat, lon, country, state}] (up to 5)
            └─ User picks one from dropdown
                 └─ tzlookup(lat, lon) → timezone string
                      └─ INSERT into user_cities
                           └─ setCities([...cities, newCity])
```

### Remove city flow
```
User clicks × on a card
  └─ DELETE FROM user_cities WHERE id = cityId AND user_id = ?
       └─ setCities(cities.filter(c => c.id !== cityId))
```

## UI Details

### Auth overlay
- Full-screen frosted overlay (same glassmorphism palette)
- Toggle between Login and Sign Up
- Email + password fields
- On success: overlay unmounts, cities load
- Small avatar circle + "Sign out" in top-right of app header when logged in

### Smaller card sizes
| Property | Before | After |
|----------|--------|-------|
| `.city-card` padding | 28px 24px | 18px 16px |
| `.city-grid` gap | 24px | 16px |
| `.city-greeting` font-size | 1.35rem | 1.05rem |
| `.city-time` font-size | 2rem | 1.5rem |
| `.weather-temp` font-size | 1.4rem | 1.1rem |
| `.city-date` margin-top | -10px | -6px |

### AddCityCard
- Dashed border, 60% opacity ghost style
- Shows `+` icon and "Add city" text at rest
- Clicking activates: input appears, dropdown below as user types
- Dropdown shows city name, state/country, flag emoji
- Disabled (hidden) when city count = 6

### Remove button
- Appears on card hover: `×` in top-right corner
- 20×20px, semi-transparent, full opacity on hover
- Pointer-events none when not hovering the card

### Strip tooltip
```
onMouseMove on .dns-bar:
  barPct = (e.clientX - bar.left) / bar.width
  hoveredOffset = barPct * 26 - 12            // -12 to +14
  round to nearest 0.5h

  nearestCity = cities.find(c =>
    Math.abs(solarMap[c.name].utcOffset - hoveredOffset) < 1.5
  )

  localTime = new Date(now + hoveredOffset * 3600000)
    .toLocaleTimeString('en-US', {hour:'2-digit', minute:'2-digit'})

Tooltip content:
  - Always: "GMT ±X" label + local time
  - If nearestCity: city name, ☀️/🌙, sunrise ↑, sunset ↓

Tooltip position: fixed above bar, clamped within bar bounds
Hidden on: mouseleave, touch devices
```

## Non-functional impacts

- **NFR-01 performance**: Supabase query on mount is ~1 network call, negligible; cities cached in state
- **NFR-04 security**: Supabase anon key is safe to expose in frontend (RLS enforces row ownership); OWM geocoding proxied through backend (key stays server-side)
- **NFR-05 maintainability**: `CITIES` constant removed from App.jsx; city data now entirely in Supabase
- **Bundle size**: `@supabase/supabase-js` adds ~50KB gzipped; `tzlookup` ~20KB — total ~70KB addition, still within budget

## Out of scope (this iteration)
- Google / social OAuth (can be added in Supabase dashboard with one toggle)
- City reordering via drag-and-drop
- City count > 6
- Password reset flow (Supabase handles this via email; no UI needed yet)
